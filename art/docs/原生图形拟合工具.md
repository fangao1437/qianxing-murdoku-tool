# 原生基本图形拟合工具（`art/tools/fit-primitive-shape.mjs`）

> 把设计图里的一块**楔形／斜边区域**拟合成严格的分段直线多边形，再用官方
> `100003` 等腰三角把凸多边形 100% 铺满，且**零溢出**。
> 主项目对应文档：`qianxing-murdoku/docs/美术资产-原生图形构造与v12-v15演进.md`。

## 为什么需要它

历史里有两种失败做法：

| 做法 | 结果 |
|---|---|
| 用大量竖直小矩形扫描斜边 | 斜边台阶/锯齿，控件数暴涨 |
| 用一枚**大钝角三角**去「盖满」细长楔形 | 覆盖是够了，但顶点越过目标轮廓 → **边缘溢出**；楔形顶端由多枚三角拼成 → **顶部分叉** |

用户给的判据是：**「三角形的斜边构造法完全够拟合该形状」**——
设计图的楔形边界本来就是几段直线，每段直线正好可以是一枚 `100003` 的底边。
所以正确流程是「先拟合边界 → 再按边界生成图元」，而不是先造一个大三角再补救。

## 三段式算法（A + B + C）

设拟合出的凸多边形为 `poly`。

- **A｜整幅每边等腰三角**：对 `poly` 的每条边 `a→b`，取内法线 `n`（指向重心），
  二分求最大深度 `h` 使 `tip = mid + n·h` 仍在 `poly` 内；放一枚 `100003`
  （`w=|ab|`、`h`、`rot=atan2(-n.x,-n.y)`、中心 `mid+n·h/2`）。
- **B｜扇形剖分补尖角**：`tri_i=(p0,p_i,p_{i+1})`，每个三角三条边各放一枚等腰三角。
- **C｜顶角三角（本工具新增）**：对 `poly` 的每个顶点 `V`，沿两条相邻边各取长度 `d`
  得到 `A,B`；以 `V` 为顶点、`AB` 为底边放一枚 `100003`。
  因为两腰等长，它天然是等腰三角；**三个顶点全在多边形边界上，零溢出是构造性保证**。
  A+B 在细长尖角处只剩 93.6% 覆盖，正是 C 把尖角补到 100%。

工具会逐档加大 C 的尺度（`[0.62]` → `[0.4,0.8]` → `[0.3,0.55,0.8,1.0]` → `[0.2,0.35,0.5,0.62,0.75,0.88,1.0]`），
每档做一次栅格覆盖率自检，达标即停。尺度恒 ≤1，保证底点不会越过相邻顶点。

## `100003` 实测几何模型（务必按此换算）

`type=image` / `imageAssetId=100003` / `imageType=stretch` / `imageTint=true`：

```
局部 w×h：顶点上中 (0,-h/2)，底边 y=+h/2 长 w
旋转 r（视觉逆时针）：(x,y) -> (x cos r + y sin r, -x sin r + y cos r)
顶点方向 = (-sin r, -cos r)
⇒ 让顶点指向内法线 n 时： r = atan2(-n.x, -n.y)
   中心 = 底边中点 + n·h/2，  底边长 w = |ab|， 高 h = 顶点到底边的垂距
rot=±90 时包围盒 w/h 交换
```

## 用法

零依赖路径（推荐，只吃 JSON）：

```bash
node art/tools/fit-primitive-shape.mjs \
  --samples=out/wedge-samples.json \
  --left-breaks=320,500 --right-breaks= \
  --color=#C85D11 --out=out/wedge-fit.json
```

`--samples` 格式：`[{"y":233,"left":473,"right":476}, ...]`
（逐行的目标色「最长连续段」左右端；可由设计图取色生成，也可用 `--save-samples` 导出）。

直接从设计图取边界（需要 `node_modules/@napi-rs/canvas`）：

```bash
node art/tools/fit-primitive-shape.mjs \
  --png=path/to/design.png --color=#C75C18 --box=380,220,500,660 --tol=12 \
  --left-breaks=320,500 --save-samples=out/wedge-samples.json \
  --out=out/wedge-fit.json
```

已有多边形、只生成图元并自检：

```bash
node art/tools/fit-primitive-shape.mjs --poly=out/poly.json --color=#C85D11 --out=out/elements.json
```

不读任何文件的自检：

```bash
node art/tools/fit-primitive-shape.mjs --self-test
```

### 参数

| 参数 | 说明 |
|---|---|
| `--samples` / `--poly` / `--png` | 三选一；边界样本 / 显式多边形 / 设计图 |
| `--box=x0,y0,x1,y1` | PNG 取样范围（配合 `--png`） |
| `--color=#RRGGBB` | PNG 取色目标，同时也是生成图元的颜色 |
| `--tol=N` | PNG 取色容差（默认 12） |
| `--left-breaks=` / `--right-breaks=` | 左右边界的分段折点 y（逗号分隔，可空） |
| `--save-samples=` | 顺手把 PNG 提取的样本存成 JSON |
| `--grid=N` | 覆盖率自检栅格步长（默认 1） |
| `--target=0.995` | A+B+C 逐档搜索的目标覆盖率（默认 0.9995） |
| `--min-coverage=99.5` | 最终闸门的最低覆盖率（默认 99.9）；细长多边形的边界栅格像素可用它放宽 |
| `--out=` | 结果 JSON；不给则打印到 stdout |

## 输出与自检

```jsonc
{
  "polygon": [[477.458,220.703],[449.654,298.66],[412.101,499.382],[456.168,653.161]],
  "lines": { "left": [...], "right": [...] },   // 每段的 x=a*y+b、MAE、MAX、样本数
  "residual": { "mae": 0.5, "max": 4.054 },
  "adaptive": { "strategy": "A+B+C", "cornerScales": [0.3,0.55,0.8,1], "coverage": 100, "elements": 26 },
  "verification": { "elements": 26, "overflowVertices": 0, "coverage": 100, "sampled": 12488 },
  "elements": [ /* 可直接塞进 scene JSON 的 type=image 图元 */ ]
}
```

自检两道闸门，任一不过即 `exit 1`：

1. **零溢出**：把每枚 `100003` 的三个顶点按 `rotate(-rot)` 还原，
   用「有向距离」判断是否在多边形内（边界上 0.5px 内视为浮点误差，不算溢出）。
2. **覆盖率 ≥99.9%**：在目标凸区内栅格采样，要求每点至少落在一枚三角内。

## 实战：警局场景 v17 的橙红楔形

设计图 1920×1080 等比缩到 1600×900，取 `#C75C18` 逐行最长连续段，得 416 行样本。
分 3 段拟合左边界、1 段拟合右边界：

| 边界 | y 范围 | 拟合直线 | MAE | MAX |
|---|---|---|---|---|
| 左上 | 233–320 | `x=-0.357y+556.173` | 1.70 | 3.67 |
| 左中 | 320–500 | `x=-0.187y+505.530` | 0.33 | 1.11 |
| 左下 | 500–649 | `x=+0.287y+268.998` | 0.61 | 4.05 |
| 右 | 233–649 | `x=-0.049y+488.323` | 0.29 | 1.52 |

四线交点即严格凸四边形，26 枚 `100003`、100% 覆盖、0 溢出。
v17 用它彻底替换了 v15/v16 的「2 个 fillTri + 2 枚大钝角三角」：

| y | 设计图左缘 | v16 左缘 | v17 左缘 |
|---|---|---|---|
| 450 | 422 | **412（溢出 10px）** | 421 |
| 550 | 427 | **404（溢出 23px）** | 426 |
| 600 | 440 | **422（溢出 18px）** | 441 |
| 660+ | 无（楔形止于 653） | 仍有 RED 到 710 | 无 |

顶端由多枚三角拼出的「分叉」也消失：顶角三角令所有边界收敛到同一个多边形顶点。

## 边界 / 已知限制

- 只处理**凸**多边形；凹形请先自行拆成若干凸块分别调用。
- 只输出 `100003` 三角图元；若目标含真正的曲线/圆弧，需要另做分段逼近。
- `100003` 只能做等腰三角，`type=polygon/triangle/path` 与自定义 `points` 会被导出器忽略。
- 历史里 `100003` 在 `.gil` 图片控件的个别旋转角曾「真机不出图」；
  本工具输出的是 `.gia` scene `image` 图元，仍需实机截图确认。
- 半透明图元**不能重叠**（会叠两层压暗）；本工具输出的都是不透明同色图元，可任意重叠。


## v18 实战：阴影按设计图完整形状构造

v17 的阴影是靠胶带/档案袋遮挡「借」边界的半透明矩形，左/上/下多处边界不完整。
v18 把设计图的阴影轮廓量成四条直线（上=POLICE 胶带下缘、左=档案袋右缘、
下=档案袋底边、右=`x=1263`），凹角拆 Q1/Q2 两个凸块，再补 TUP（胶带上方深棕三角）
与 TLEFT（胶带下方较亮红棕三角），按 x 分 3 带取设计图实测色，
共 8 块 / 114 枚 `100003`，覆盖率 99.555–100%、0 溢出。

生成方式：先用 Sutherland–Hodgman 把 Q1/Q2 按 x 带裁成凸多边形，
再对每块跑 `--poly`；细长块的边界栅格像素用
`--target=0.995 --min-coverage=99.5` 放宽闸门（几何零溢出仍严格判定）。
产出合并为 `shadow-elements.json`，由 `build-v18.cjs` 直接消费。
