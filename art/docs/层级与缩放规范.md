# 层级与缩放规范（模板家具）

> 目标：**地板 → 地毯 → 家具 → 墙/门/笔记/头像**，家具压在 face 上、但永远不盖头像/墙。
> 本文给出运行时节点顺序、兄弟索引、缩放与跨格偏移的精确口径，与 `art/tools/slice-layout.mjs` 的输出一一对应。

---

## 1 运行时节点图（每格）

```
board
 └─ cell.r.c                     （cell 模板实例：点按交互 + 覆盖层）
      └─ content
           ├─ face                             ← 脚本实例化 cell.face，命名 face，SiblingIndex 0
           ├─ furni.cell.r.c|rug               ← 地毯模板实例，SiblingIndex 1
           ├─ furni.cell.r.c|chair / …         ← 其它家具模板实例，SiblingIndex 2
           └─ hint / wall.* / door.* / note / portrait / x
```

- `content` 里**不再有** `obj*` / `furn` 这些手搭层容器（新架构：face 与家具都是运行时实例）；
- 旧架构（手搭层）里家具写在 `content` 的 `obj…obj12` 层上，`furn` 容器 12 层封顶——已经被新架构取代。

## 2 兄弟索引（`SetSiblingIndex`）

| 层 | 索引 | 谁写 |
|---|---|---|
| `face` | **0** | 脚本 `_ensure_cell_face`（实例化后 `SetSiblingIndex(0)`） |
| 地毯 | **1** | 脚本 `_spawn_furn_tpl`（`ckey == "rug"`） |
| 其它家具 | **2** | 同上（非 rug） |
| 覆盖层 | 3+ | cell 模板静态子控件（hint/wall/door/note/portrait/x） |

> ⚠️ 索引是"在 `content` 子列表里的位置"，不是全局；插入新层时先确认 `content` 的最终子列表。
> `SetSiblingIndex` 越界会静默失败 —— 插入后建议回读 `GetSiblingIndex()` 并打日志。

## 3 尺寸与缩放

模板层在规格里按 **1 格 = 108 画布像素** 写死。运行时：

```
f      = 格子宽(px) / 108            # 5×5 关 = 1.0；6×6 关 ≈ 0.83
层宽px = 规格 w × f
层高px = 规格 h × f
层位置 = 实例中心 + (规格 dx, 规格 dy_down) × f   （y 轴：画布向上为正 ⇒ 下移取负）
实例尺寸 = (跨格列数 × 格子宽, 跨格行数 × 格子高)
```

- **实例本身不缩放**（`SetSizeDelta` 设成跨格尺寸），**逐个子层**按 `f` 缩放（等价于模板实例的"画布适应"）；
- 长桌：模板画布本来就按 216×108 / 108×216 设计，实例=2 格 × 1 格，子层仍按 `f` 缩放；
- 地毯：模板按 108×108（1 格）设计，跨格时实例按包围盒拉伸 ⇒ 边框按比例变粗（可接受；若要求"边框恒宽"需按跨格数分变体）。

## 4 跨格件的位置（锚点格 + 整件中心偏移）

`slice-layout.mjs` 输出：

```jsonc
{ "name": "长桌", "kind": "table", "templateKey": "furn.table.h2",
  "anchor": { "r": 1, "c": 2 },              // 锚点格 = 包围盒右下格
  "span": { "r": 1, "c": 2 },
  "offsetCells": { "dx": -0.5, "dy": 0 } }   // 整件中心相对锚点格中心（单位=格）
```

脚本侧换算（格 → 像素）：

```
实例中心 = 锚点格中心 + (offsetCells.dx × 格子宽, -(offsetCells.dy × 格子高))
```

> `dy` 在 JSON 里"向下为正"，写进 `SetAnchoredPosition` 时要取负（画布 y 向上）。
> 锚点格必须选在**包围盒右下格**：跨格件靠"把锚点格抬到同级最上层"来避免被邻格压住。

## 5 切关与层级重放

- 切关：销毁上一关的全部家具实例、清缓存（`furn_level` 属性变化触发）；
- face 实例是**每格常驻**的（不随切关销毁），只在格子重建时重建；
- 若同一帧里既有"属性先到"又有"格子重建"，用"恒受理 + 关卡到达后补造"（本仓库对应主项目 v313 起的做法），
  不要依赖属性到达顺序。

## 6 验收清单

1. 进关：地板（face）先出现，家具压在地板上；
2. 家具**不盖头像/墙/门/笔记**；
3. 长桌/地毯跨格连续、无接缝；
4. 切关：上一关家具全部消失、下一关重建、无重影；
5. 6×6 关（格子 ≈89px）家具按 `f≈0.83` 缩放后不溢出格子（允许跨格件按 span 溢出）。
