## 三 ★★ 怎么装 / 怎么恢复（★ 换机或重装照这个做 ✓）

```powershell
# 0) 目标 profile（桌面端）
$profileDir = "$env:USERPROFILE\.dsh\profiles\desktop\node_modules"

# 1) 从本仓把插件目录整个复制过去（8 个都这么干）
Copy-Item "dsh-plugin-qianxing-art-pipeline" "$profileDir\" -Recurse -Force
# …其余 7 个同理

# 2) 重扫核对（本仓脚本）
node tools/scan-installed-plugins.mjs

# 3) 重启 DSH 桌面端（插件在启动时装配）
```

★ **注意** ✓：
- ★★ **`beyond-simulator` 是 GPL-3.0-only** ✓ —— ★ 再分发/修改要守 GPL 条款 ✓（其余 MIT ✓）
- ★★ **别手工改 `node_modules` 里的插件的 `package.json` 版本号** ✗ —— ★ 我们的核对靠它 ✓
- ★★★ **客户端 UI 类插件**（如模拟器面板）改了要**刷新页面**才生效 ✓（★ 有 `pnpm run dev:web` 才会自动 HMR ✓）
- ★★ **web profile 那份 `beyond-simulator` 是 v2.0.2** ⚠️ —— ★ 要么同步成 2.0.8 ✓，要么别用 web profile 打开模拟器 ✓

## 四 ★★ 版本核对结果（★ 2026-10-30 ✓）

```
★ 8 个项目插件：已装版本 == 仓内版本 ✅（0 处漂移 ✓）
★ 唯一不一致：web profile 的 beyond-simulator v2.0.2 ✗（desktop 是 2.0.8 ✓）
★ 官方系统包 2 个：不参与项目分发 ✓
```

★ **怎么自己再核一遍** ✓：
```powershell
# 逐个读版本
Get-ChildItem "$env:USERPROFILE\.dsh\profiles\desktop\node_modules\dsh-plugin-*" -Directory |
  ForEach-Object { $p = Get-Content "$($_.FullName)\package.json" -Raw | ConvertFrom-Json; "$($p.name)  v$($p.version)" }
```
