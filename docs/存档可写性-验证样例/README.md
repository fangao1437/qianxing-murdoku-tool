> 目的：**不用 Blender / GIA / 账号**，只改存档里的坐标，把元件摆到位。
> 我需要先验证「存档可离线改写」这件事，所以请按下面放文件。

## 1 必须给：可用存档（原始文件，不要截图）

| 文件 | 说明 |
|---|---|
| `save-原始.gil`（或编辑器导出的原始扩展名） | **所有元件已经在里面**、位置是随便摆（占位）的版本 |
| `save-对照.gil`（可选但强烈建议） | 你**手动在编辑器里摆好目标位置**后另存的版本 —— 拿它跟原始档做二进制/结构对比，能最快确认坐标字段是哪几个字节 |

如果只能给一份，就给**原始档**（元件齐全、坐标随意）；我靠解析结构找坐标字段。

## 2 必须给：元件清单

`components.csv`（或 json），一行一个元件：

```csv
id,name,prefab,instance_count,note
elem-1,桌子A,prefabs/table_a,1,场景里唯一
elem-2,椅子A,prefabs/chair_a,4,四把一样的
```

- `prefab`：元件在存档里的**标识**（prefab 路径 / 资源 ID / 名称都行，越原始越好）
- 如果同一个 prefab 有多个实例，`instance_count` 写数量，我会按出现顺序给它们编号

## 3 必须给：目标坐标表

`coordinates.csv`（或直接给我设计图+比例，我来换算）：

```csv
id,x,z,y,rotYDeg,scale
elem-1,2.0,3.2,0,0,1
elem-2a,1.1,3.2,0,90,1
elem-2b,2.9,3.2,0,270,1
```

- 单位米；坐标系：**x 向右 / z 向前（俯视图向下）/ y 向上**（与插件 SceneSpec 一致）
- `y` 是元件**底面中心**高度（放地上就是 0）
- `rotYDeg`：绕竖轴朝向（0=面向 -z，顺时针为正；不确定就写 0，我按存档里的默认朝向对齐）
- `scale`：可不填（默认 1）

## 5 我会先做什么（拿到文件后立刻跑）

1. `save_scene_inspect`：解析存档容器，列出记录类型、元件实体（prefab/坐标/朝向/缩放）、模板与引用；
2. 用「原始档 vs 对照档」做 diff，定位**坐标字段**与是否带哈希/校验；
3. 出**可写性报告**：
   - ✅ 可写 → 直接做 `save_scene_place`（输入存档+坐标表 → 输出新档 + 四门禁：重读/往返/幂等/引用校验），并接到云端 CLI（纯 Node，云上可跑，不需要 Blender/账号）；
   - ❌ 不可写（加密/需编辑器生成/有签名）→ 退化成「插件只出 placement 清单」，你在编辑器里按坐标点，仍然不用 GIA/Blender。

> 注意：**绝不覆盖原档**。所有输出都写新文件，原档保留。
