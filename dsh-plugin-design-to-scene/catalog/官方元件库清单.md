## 文件

| 文件 | 用途 |
|---|---|
| `official-prefabs.json` | 全量规范化清单（程序读取） |
| `official-prefabs.csv` | 表格版（Excel / 检索 / 人工挑素材） |
| `kind-map.json` | SceneSpec kind → 候选官方 prefab（按关键字规则预筛） |
| `search.mjs` | 检索 CLI：按名字/分类/尺寸找元件 |

## 用法示例

```bash
# 按名字搜（模糊，支持中文）
node catalog/search.mjs --name 桌

# 按分类 + 尺寸范围（米）
node catalog/search.mjs --category 人造装饰 --min 0.5 --max 2

# 按 SceneSpec kind 找候选
node catalog/search.mjs --kind table

# 导出 JSON（给后续流水线用）
node catalog/search.mjs --name 灯 --json
```

## 和「设计图 → 场景」流水线怎么接

1. 设计图解析 / 代理看图画出的 `SceneSpec` 里，每个物件有 `kind` + 近似尺寸 `size`；
2. `kind-map.json` 给出该 kind 的候选官方 prefab 列表；
3. 用 `search.mjs --kind <kind>` 或按尺寸过滤，挑出最接近的 prefab ID 和名字；
4. 把 prefab ID / 名字写进「坐标表」（元件名 → 目标坐标/朝向），交给存档改写工具；
5. 存档里的 3D 元件记录（`#5→#1→#6→#11`）只改位置/旋转/缩放，不生成新元件。

## 刷新方式

渊星工具箱更新素材后，重新运行：
```bash
node _work/make-official-catalog.mjs        # 从 %LOCALAPPDATA%\Yuanxing\... 重新生成 catalog/
```

> 注意：这是**官方元件库**（游戏造物/场景物件），不含自定义 GIA 资产；自定义资产另需 GIA 清单。
