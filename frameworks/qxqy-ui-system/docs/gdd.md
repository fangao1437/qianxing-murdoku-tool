# 千星「翻页单击活动」UI 框架 · 策划案（GDD）

> 本文件的"玩法"是一个 **UI 框架的契约**，不是具体活动内容。
> 布局与内容设计按用户要求**留白**，后续逐步填充；框架只负责"页 / 屏 / 输入 / 状态 / 桥"这几件事。

## 1. 目标与范围

| 项 | 内容 |
|---|---|
| 目标 | 在客户端 Lua 侧提供一套**多屏多页、点击驱动**的活动界面骨架：屏注册、页翻页、页签跳转、按钮状态、键盘/指针输入、服务端信号桥 |
| 参照 | 教程资产 `教程UI系统_翻页单击活动样式.gia` 的**角色构成**（页签 / 左右翻页 / 四态素材组 / 内容视窗 / 装饰层 / 关闭键），解析见 `docs/gia-structure.md` |
| 不做（P0 之外） | 具体活动文案与关卡内容、美术走图与动效、真机联机校验、手柄导航落地（只留接口） |
| 底线 | 框架不能因为"控件没摆"而崩；发现 0 个屏时安静待命并打一行诊断 |

## 2. 核心循环（框架视角）

```
生命周期 OnInit/OnStart → 发现控件（按名字约定）→ 建索引 → 接输入 → 打开第一个屏（第一页）
    ↓（事件驱动，无逐帧轮询）
点击 tab.<页id> → 跳到 page.<页id>
点击 btn.prev / btn.next → 顺序翻页（默认到头钳制，可配成循环）
点击 btn.reset → 当前页重置钩子
点击 btn.close → 屏根 SetVisible(false)（保持 active）
键盘 Left/Right/A/D/Esc → 同上动作（PC 画布）
每次页变化 → 本地先改 UI → 发信号 ui/nav（服务端节点图写变量）
服务端下发 ui/sync → 客户端以服务端为准校正（幂等）
```

## 3. 输入契约

| 输入 | 绑在哪 | 说明 |
|---|---|---|
| 指针点击 | `tab.*`、`btn.prev/next/close/reset` 这些**预设按钮** | 只有预设按钮/光标检测区域/网格视窗能收光标事件；容器 `showCursor` 必须为真（本工程已在存档里置真） |
| 键盘 | 候选控件 `app.root` → `screen.*`（取第一个支持 `AddKeyEventListener` 的） | 键名先试 `Enum.KeyboardKeyCode.*` / `Enum.KeyCode.*`，都不存在时用字符串；**实测字符串可用** |
| 长按 | 无官方事件，框架 `Input.hold()` 用 Down/Up + dt 累加实现 | 默认不启用；需要时再挂 |

## 4. 胜负/成功判定

框架没有胜负，只有**不变量**（见 §5）。活动内容的胜负由后续填充的业务页自行定义，并通过 `App.register_reset(page_id, fn)` 等扩展点接入。

## 5. 不变量（可断言，已写进测试）

1. **单一可见性权威**：屏可见性只由 `Screen.apply()` 写，页可见性只由 `Pager.apply()` 写，`state.sel/state.off` 只由 `State` 写。其它地方只改"期望值"。
2. **同一时刻一个屏、一页**：`page.pX` 里除当前页外全部 `visible=false`。
3. **屏根恒 active**：切屏只 `SetVisible`，容器不隐藏（隐藏容器会销毁其内客户端控件）。
4. **首帧不白屏**：boot 时对根/屏根显式 `SetActive(true)`（`active` 默认 false 且只读）。
5. **命名唯一**：`screen.* / page.* / tab.* / btn.* / hud.* / app.*` 不得重名（重复会在诊断里报 `dup_bad`）。
6. **状态与内容解耦**：翻页顺序 = 编辑器同级顺序，不由名字排序决定。

## 6. 名字约定（布局留白时唯一需要遵守的东西）

| 名字 | 类型 | 作用 |
|---|---|---|
| `app.root` | 容器节点 | 整屏根（客户端控件容器画布里的默认容器节点），脚本挂这里 |
| `screen.<id>` | 容器节点 | 一个界面；同时只有一个可见 |
| `page.<id>` | 容器节点 | 一页；顺序 = 编辑器同级顺序 |
| `tab.<id>` | 预设按钮 | 点它跳到 `page.<id>`；子控件可带 `state.sel` / `state.off` |
| `btn.prev` / `btn.next` | 预设按钮 | 上一页 / 下一页 |
| `btn.reset` | 预设按钮 | 重置当前页内容（走注册的 resetter） |
| `btn.close` | 预设按钮 | 关闭当前屏 |
| `hud.pager` | 文本框 | 页码，格式 `%d / %d` |
| `hud.title` / `hud.body` | 文本框 / 文本视窗 | 标题 / 正文 |
| `state.sel` / `state.off` | 任意 | 某个可选中控件的选中/未选中视觉（互斥显隐） |
| `text` / `plate` / `label` / `bg` | 任意 | **局部子名**，允许重复（框架只按名字索引语义名） |

## 7. 风险与 UNKNOWN

| 风险 | 处理 | 最晚验证阶段 |
|---|---|---|
| 真机 `AddKeyEventListener` 挂在容器节点上未必支持 | 框架列候选控件并只记录 `KEY_SKIP`，键盘属加分项 | 真机（步骤 7） |
| 真机四态按钮的"按下/悬停"表现是否与编辑器预览一致 | 交编辑器四态，Lua 不碰；真机核对 | 真机 |
| 编辑器里给控件改名会让按名查找失配 | 诊断里 `missing=` 会点名缺失名字 | 每次试玩 |
| 传送/断线重连销毁全部客户端控件 | 框架 `Bind.invalidate()` + `App.boot` 可重入设计；**恢复逻辑待补** | 真机（步骤 7，UNKNOWN） |
| 文本换行/自适应字号与真机差异 | 只做"文本可读"的最低承诺，细节进真机核验清单 | 真机 |
